# CLAUDE.md

Указания для Claude Code при работе с этим репозиторием.

## Что это

Статический одностраничный сайт агентства AGILY. Весь сайт — один файл `index.html`
(~1700 строк): разметка, `<style>` со всеми стилями, `<script>` со всей логикой и
словарём переводов. Сборки, npm, зависимостей и тестов нет.

## Запуск и проверка

```bash
open index.html                 # быстрая проверка
python3 -m http.server 8000     # если нужны корректные пути/видео
```

Проверять изменения нужно глазами в браузере — автотестов нет. Обязательно смотреть
оба языка (EN и TH) и оба брейкпойнта (≤860px, ≤480px).

## Устройство index.html

Ориентируйся по маркерам-комментариям, а не по номерам строк — они плывут:

- CSS-блоки помечены `/* ---------- HERO ---------- */`, `NAV`, `INTRO 01/02`,
  `RESPONSIVE` и т. д.
- Секции разметки помечены `data-screen-label` (`01 Home` … `05 Contact`).
- JS-блоки помечены `// ---------- WORK CAROUSEL ----------`,
  `SERVICES horizontal scroller`, `LANGUAGE TOGGLE` и т. д.

Порядок в файле: `<style>` → `<main>` с секциями → `<script>`. Новый код клади в
соответствующий по смыслу блок, а не в конец файла.

## Правила, которые важно соблюдать

**Любой текст на странице должен быть переводимым.** Добавляя видимую надпись,
поставь `data-i18n="ключ"` (или `data-i18n-aria` для `aria-label`) и добавь ключ
в **оба** словаря — `translations.en` и `translations.th`. Тайские строки без
перевода оставлять нельзя: `setLanguage` подставляет значение через `innerHTML`,
и отсутствующий ключ просто молча оставит английский текст.

**HTML внутри переводов — норма.** Значения словаря вставляются как `innerHTML`,
поэтому там встречаются `<strong>`, `<span class="accent">`, `<br/>`, `&amp;`.
Сохраняй эту разметку при правках и экранируй амперсанды как `&amp;`.

**Медиа.** На сайте используется только `assets/`. Картинки — WebP, видео — MP4.
`uploads/` в `.gitignore`, `original/` не коммитится — это архив исходников,
не подключай их из HTML. Новые изображения клади в `assets/work/` или
`assets/services/` по существующей схеме имён (`matchday-1.webp`,
`03-design.webp`).

**Стиль кода.** Vanilla JS без библиотек, `const`/`let`, IIFE для изолированных
блоков (`initServices`), обращения к DOM через `data-*`-атрибуты
(`data-work-prev`, `data-services-scroller`), классы в стиле BEM
(`work__slide`, `service-card__title`). Не тащи сюда фреймворки, сборщики и
внешние скрипты — сайт должен открываться двойным кликом по файлу.

**CSS-переменные** объявлены в `:root`: `--ink`, `--ink-dim`, `--ink-faint`,
`--bg` (`#0e0a18`), `--rule`. Новые цвета брать оттуда, а не хардкодить.

**Анимации** должны отключаться при `prefers-reduced-motion: reduce` — правило
уже есть, добавляя новую анимацию, допиши её в этот блок.
