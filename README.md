# AGILY — сайт агентства

Одностраничный сайт маркетингового агентства AGILY (Бангкок). Полностью статический:
весь HTML, CSS и JavaScript лежат в одном файле [index.html](index.html), сборки нет,
зависимостей нет, npm не используется.

**Стек:** vanilla HTML/CSS/JS, шрифты Space Grotesk + Noto Sans Thai (лежат в `assets/fonts/`), медиа в WebP/MP4.

## Запуск

Достаточно открыть файл в браузере:

```bash
open index.html
```

Либо поднять локальный сервер (нужен, если хочется корректных относительных путей и
проверки видео/кэширования):

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Структура

```
index.html          весь сайт: разметка, стили, скрипты, словарь переводов
robots.txt, sitemap.xml, 404.html, _redirects, _headers
                    служебные файлы для поисковиков и Cloudflare Pages
assets/             продакшн-медиа, отдаётся на сайте
  favicon.png
  agily-logo.png
  og-image.jpg          превью ссылки в соцсетях, снимок первого экрана (1200×630)
  hero-turbine.webp     фон первого экрана
  contact-bg.webp       фон блока контактов
  work/                 кейсы: matchday-*, monkey-*, handsup-*, dksh-1, mea-film.mp4
  services/             фоны карточек услуг: 01-advertising … 05-production
new-data/           новые исходники заказчика; сайт напрямую их не загружает
uploads/            исходники и промежуточные версии картинок (в .gitignore)
original/           оригиналы в полном разрешении (не закоммичено)
```

В репозиторий попадает только `assets/` — это единственная папка, на которую ссылается
сайт. `uploads/` и `original/` — рабочий архив исходников.

## Секции страницы

Каждая секция помечена атрибутом `data-screen-label`:

| Секция | id | Что внутри |
| --- | --- | --- |
| 01 Home | `#home` | Полноэкранный герой, навигация, переключатель языка |
| 02 Intro | `#intro` | Два экрана: заявление о позиционировании и «THE WORK SPEAKS» с пилюлями категорий |
| 03 Work | `#work` | Кейсы, сгруппированные по категориям — см. ниже |
| 04 Services | `#services` | Горизонтальная галерея из пяти карточек услуг |
| 05 Contact | `#contact` | Логотип, навигация, соцсети, контакты, «back to top» |

Кейсы внутри `#work` разбиты на категории; у каждой свой заголовок и свой якорь:

| Категория | id группы | Кейсы |
| --- | --- | --- |
| 01 PRODUCTION | `#work-production` | `#work-mea` (видео) |
| 02 SOCIAL CONTENT | `#work-social-content` | `#work-matchday`, `#work-monkey`, `#work-handsup` |
| 03 EVENT | `#work-event` | `#work-dksh` |

Пилюли в блоке Intro — ссылки `href="#…"` на соответствующую группу.

## Что умеет фронтенд

- **Двуязычие EN/TH.** Переключатель в шапке; словарь `translations` в конце
  [index.html](index.html), подстановка по атрибутам `data-i18n` (в `innerHTML`) и
  `data-i18n-aria` (в `aria-label`). Язык определяется адресом: `/` — английский, `/?lang=th` — тайский.
  EN/TH — ссылки на соответствующие версии, доступные поисковым роботам.
- **Карусели кейсов.** MATCHDAY и MONKEYEVERYDAY содержат по 8 изображений,
  в порядке номеров файлов из `new-data/matchday Size 1080x1080 (main)` и
  `new-data/monkeyeveryday 1080x1350 (main)`. HANDSUP содержит 12 квадратных
  изображений из `new-data/Handsup Size 1080x1080 (main)` в порядке
  `11, 22, …, 99, 1010, 1111, 1212`; точки расположены в два ряда.
  Все три карусели поддерживают стрелки,
  точки, свайп, клавиши ←/→, счётчик и переход от последнего кадра к первому.
- **Формат макетов.** MATCHDAY и HANDSUP — квадратные, MONKEYEVERYDAY — вертикальный 4:5.
  На телефоне макеты занимают доступную ширину; название и кнопки находятся
  за пределами изображения. На больших экранах ширина ограничена 720px и 576px
  для квадратных и вертикальных макетов соответственно. WebP подготовлены без обрезки и увеличения исходников,
  ширина до 1440px. В URL используется хэш содержимого для обновления кэша.
- **Кадр показывается целиком.** Слайд рисует картинку дважды: размытая подложка на
  весь экран (`cover`) и поверх неё сама картинка целиком (`contain`). Макеты любого
  соотношения сторон видны полностью и не растягиваются. Видео-кейс работает так же
  (`object-fit: contain`).
- **Галерея услуг.** Горизонтальный скролл: кнопки, перетаскивание мышью, свайп и
  горизонтальный жест трекпада. Вертикальное колесо всегда прокручивает страницу.
- **Плавный скролл** по стрелкам, пилюлям категорий и ссылкам блока контактов.
- **Доступность и motion.** `aria-label` / `aria-pressed` на интерактивных элементах,
  анимации появления отключаются при `prefers-reduced-motion: reduce`.
- **Адаптив.** Брейкпойнты 860px и 480px (плюс 720px для блока услуг).
